# Security Policy

## Supported Versions

Security updates are only applied to the latest version of Watchtower. When you use the `latest` tag, Watchtower keeps
itself up to date, so you receive these updates automatically as soon as they are released.

Images are rebuilt on every change to `main` and are scanned for known vulnerabilities before they are published.

## Reporting a Vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/dallergy/watchtower/security/advisories/new) rather than in a public
issue. You will receive a response as soon as possible, but keep in mind that this is a community project without
guaranteed response times.

Non-critical issues may be reported as regular GitHub issues.
